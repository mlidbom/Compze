### Tessaging and Typermedia documentation added
[Tessaging](~/Compze/Tessaging/_docs/introduction.md), Compze's type-routed messaging, now has eight pages of documentation: from declaring tessage types, through endpoints, to the processes of one application conversing on one machine with nothing to configure. [Typermedia](~/Compze/Tessaging/Typermedia/_docs/introduction.md) has four, on declaring and navigating typermedia APIs. Every example on them is compiled code.

The [Teventive](~/Compze/Teventive/Taggregates/_docs/definition.md) pages now use the names the code does: tevents and taggregates.

# Rationale: a Compze API spends nothing on what its callers can do as well themselves

Added 2026-11-17 on Magnus's word, after a case in the taggregate store spike (items 34 to 37 of jastudio-rep-opus's
list, dev_docs/taggregate-improvements/shared/the-taggregate-store-build-log.md).

What the agent did: Opus 5.5 (claude-opus-5-5) gave two reads an order. An index's `Lookup` returned its references in
id order, after JAStudio's rebuild changed 1,172 sentences because a lookup that took the first of several vocab got
them in the store's own order. The bulk reader's `All` then got the same order, for consistency between the stores. The
agent measured the cost at JAStudio's size, 8.5 ms and 2.9 MB a call at 80,000 ids, reported it, and kept the order.

What it missed, which Magnus saw: a library can't know its callers' sizes. At a million ids the sort added about 137 ms
and 36 MB to each call of `All`, six times the gathering of the ids, and as much to each lookup inside a unit of work,
for a key that files most of a store, such as a tag. Magnus: "What does that add up to with a store of millions of
objects? That is entirely possible and may well happen in JAStudio. At those added costs the sort may well be more
expensive than the operation the client code was going to perform on the objects.... Client code that does not care
about ordering should not need to pay for it". And, when the agent assumed lookups give small groups: "Who says that an
index lookup will never return really large numbers of objects?"

Both orders were dropped, and both reads return an IReadOnlyCollection. JAStudio, which needed the order for a
reproducible rebuild, sorts in its one call of Lookup, and skips the sort for groups of one or none. The rule's
sentences are Magnus's, from his decision: "And if it is for a search, they would do the sort after the filter and then
instantly the cost dropped a lot since the collection is smaller".

Why a rule: the agent would not have done this by itself. It had the measured cost in hand and judged by the sizes in
front of it. The rule names the case it is most often about, ordering, and what the type then says.
